# Crystal–conductivity pairs

Use `grace_low2.csv` for the 1,712 low-κ potential labels and `dft_low2.csv`
for the 58 low-κ DFT labels. Paths are relative to this directory.
All completed labels are in `grace_results.csv` and `dft_results.csv`, with
matching typed JSONL exports. See [data documentation](../docs/DATA.md) for
geometry roles, units, aliases, quality flags, source terms and download links.

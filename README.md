# DANA-κ

**Distribution-Aware Neighborhood Attention for lattice thermal conductivity prediction and materials screening.**

This repository is being prepared as the open-source home for DANA-κ and a multilevel workflow for identifying crystal phases with ultralow lattice thermal conductivity.

## Planned components

- **Direct property prediction:** predict lattice thermal conductivity from crystal structures with DANA-κ.
- **Candidate selection:** apply physical-property rules and computational-budget estimates.
- **Potential-assisted transport:** evaluate phonon transport with GRACE and phono3py.
- **First-principles validation:** verify selected structures with DFT and document their numerical settings.
- **Reproducibility:** provide evaluation protocols, dataset manifests, and postprocessing examples.

## Release status

The repository is initialized with this project overview. Source code, trained checkpoints, data availability, licensing, and reproduction instructions are being organized for subsequent updates.
